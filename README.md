# PPEI2-B3-Team_D Project Website

## 📋 Project Introduction

This is the final presentation website for the **PPEI (Le Projet Personnel d'Etudes et d'Insertion) 2** course.

This website records the various tasks completed by our team during the PPEI course, including speed dating sessions, professional interviews, professional network building, and interdisciplinary skill development.
